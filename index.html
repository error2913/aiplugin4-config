生成的配置



    

      
      
      
      
      
      
    


    

      怎么用？
      
    
        
  1. 点「+ 添加」或卡片上的「编辑」，在右侧面板里填好连接。
    2. 
        
  2. 模型可以点「自动拉取模型列表」选，也可以手动输入；留空则插件启动时自己拉。
    3. 
        
  3. 在「用途绑定」里指定各用途用哪个模型；留空则由插件按该用途的候选顺序取第一个。
    4. 
        
  4. 点「复制全部」，粘到 SealDice WebUI →「JS插件」→「插件设置」→ aiplugin4 →「模型」→ 模型配置。
    5. 
        
  5. 重载 JS 生效。
    6. 
        
  6. 已有配置想接着改？点「导入…」把当前配置粘进来，改完再复制回去。
    7. 
      

      

        本工具不会自动写入海豹 —— 纯静态页面访问不到你的海豹实例，只负责生成正确文本。

生成的「联网配置」

      

        
        
      

    


    


    


    

      
      
      
      
      
      
    


    

      怎么用？
      
    
        
  1. 点「+ 添加 provider」或卡片上的「编辑」，选接入方式（DeepSeek / SearXNG / 自定义）。
    2. 
        
  2. DeepSeek 只需填 API Key；SearXNG 一般不用改地址。
    3. 
        
  3. 自定义（generic）用 JSON 描述请求与取数字段，任何返回 JSON 的搜索接口都能接。
    4. 
        
  4. 点「复制全部」，粘到 SealDice WebUI →「JS插件」→「插件设置」→ aiplugin4 →「联网」→ 联网配置。
    5. 
        
  5. 重载 JS 生效。已有配置可用「导入…」接着改。
    6. 
      

      

        本工具只生成文本，不会自动写入海豹；字段与插件侧 schema v1 对应。
      

    

  



















  

    
导入配置

    
  

  

    

      粘贴一份 v5 配置（就是「模型配置」里的内容）。导入会替换当前所有连接与用途绑定。
      校验不通过时不会改动任何东西。
